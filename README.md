## `我的产品方法`

`发现问题` → `定义需求` → `拆解能力边界` → `制作原型` → `验证与迭代`

- **先确认用户价值**：明确目标用户、核心场景和需要解决的真实问题。
- **再设计 AI 边界**：区分模型擅长的理解与生成，以及工具必须保证的状态、规则和结果。
- **用原型降低不确定性**：通过可运行 Demo、架构图和任务流程验证产品假设。
- **以证据推动迭代**：区分事实、推断和建议，不用未经验证的数据包装结果。
