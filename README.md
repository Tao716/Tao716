## 🧭 我做项目时会关注

- **问题是不是真实**：先理解用户和场景，再决定要不要做。
- **AI 有没有必要**：能用确定性规则解决的事情，不强行交给模型。
- **边界怎么划分**：模型负责理解与生成，工具负责状态、规则和确定性结果。
- **原型能不能尽快验证**：先做出一个能体验的版本，再根据反馈继续改。
- **结论能不能复盘**：把事实、判断和未知项分开，方便下一次迭代。

## 🔭 最近在做

- 探索更自然的 **AI 原生交互**，让复杂的模型能力变成用户能理解、能控制的体验。
- 把产品拆解、用户研究和 Agent 设计沉淀成可复用的 **分析框架与 Skills**。
- 用小而完整的原型验证想法，从“功能能不能做”走向“产品值不值得做”。
