## 关于我

### 把模糊的 AI 想法，推进成可验证的产品

我是 **陶越**，一名专注于 **AI 原生产品、Agent 工作流与内容创作工具** 的产品经理。

我从真实场景出发，把用户需求、模型能力与产品目标连接起来；通过产品定义、快速原型和效果评测验证关键假设，推动方案从概念走向可体验、可迭代的产品。

`用户洞察`　`AI 产品设计`　`Agent 工作流`　`快速原型`　`效果评测`

> **工作路径：** 发现问题 → 定义边界 → 构建原型 → 验证价值

---

<table>
<tr>
<td width="50%" valign="top">

### 🧭 我做项目时会关注

- **问题是不是真实** — 先理解用户和场景，再决定要不要做
- **AI 有没有必要** — 能用确定性规则解决的，不强行交给模型
- **边界怎么划分** — 模型负责理解与生成，工具负责状态与规则
- **原型能不能尽快验证** — 先做出能体验的版本，再按反馈改
- **结论能不能复盘** — 把事实、判断和未知项分开

</td>
<td width="50%" valign="top">

### 🔭 最近在做

- 探索更自然的 **AI 原生交互**，让复杂的模型能力变成用户能理解、能控制的体验
- 把产品拆解、用户研究和 Agent 设计沉淀成可复用的 **分析框架与 Skills**
- 用小而完整的原型验证想法，从"功能能不能做"走向"产品值不值得做"
