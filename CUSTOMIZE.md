# Customize this profile

The public profile is generated from `README.md` and `assets/cyber-header.svg`.

- Change the headline inside `assets/cyber-header.svg`.
- Update the public projects in the `featured_processes` table.
- Adjust the snake colors in `.github/workflows/snake.yml`.
- Run the **Generate cyber contribution snake** workflow manually after the first push if the image has not appeared yet.

The repository name must remain exactly `Tao716` and it must stay public for GitHub to render the profile README.
